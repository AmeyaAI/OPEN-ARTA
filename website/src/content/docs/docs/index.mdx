ARTA is an open-source platform that generates tests from your requirements and
source code, executes them across six runtimes, and reports what your system
actually does — with every failure attributed and every test traceable back to
a requirement.

If you are new, the shortest path is **Getting started → Your first test run**.
It takes one `docker compose up -d` and a local Ollama model.
